# WebFiles

A lightweight web-based file manager and editor that allows users to manage files and directories on a server through a browser.

## Features

- **File Management:** Create, rename, copy, move, and delete files and directories.
- **File Upload & Download:** Upload files to the server and download existing files.
- **File Editor:** Open, edit, and save text files directly in the browser.
- **File Preview:** Preview images, videos, audio files, and PDF documents.
- **Directory Navigation:** Browse directories, search for files, and manage multiple selected items.
- **Access Control:** Supports HTTP Basic Authentication to restrict access.

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Enter` | Open selected file or directory |
| `Backspace` | Go to parent directory |
| `F2` | Rename selected item |
| `Delete` | Delete selected items |
| `F5` | Refresh directory listing |
| `Ctrl + A` | Select all items |
| `Ctrl + C` | Copy selected items |
| `Ctrl + X` | Cut selected items |
| `Ctrl + V` | Paste copied or cut items |
| `Ctrl + S` | Save the currently opened file |
| `Esc` | Close context menu |
| `Tab` | Insert a tab character in the editor |

The application provides a simple interface for managing server side files without requiring direct access to the server's file system.
